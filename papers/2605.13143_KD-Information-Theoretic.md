## TL;DR

- Teacher 학습과 student(distillation) 학습을 **두 개의 결합된 stochastic process**로 모델링하고, 그 사이의 KL divergence를 **distillation divergence** $K_n$으로 정의한다.
- $K_n$을 매개로 student의 일반화 gap을 teacher의 일반화 gap과 연결하는 **상한(sub-Gaussian + stability)**과 **하한((η,c)-central condition)**을 각각 증명한다.
- teacher의 **local sharpness(flatness)**를 명시적으로 넣은 bound를 유도하고, teacher가 충분히 평평하면 global 상수만 쓰는 bound보다 **엄밀히 더 타이트해지는 반경 구간** $(0,\rho_0)$을 특정한다.
- **linear Gaussian case study**에서 $K_n$을 teacher의 bias/variance, student의 rank-bottleneck 근사 오차, covariance 불일치, posterior spread로 **정확히 분해**해 설계 체크리스트로 제시한다.
- 이 논문은 **순수 이론 논문**이다. 실험적 검증(large-scale benchmark에서 $K_n$과 실제 일반화 gap의 상관관계 확인)은 "Future Work"로 명시적으로 남겨져 있고, 본문에 수치 실험이나 case study 시뮬레이션은 전혀 없다.

## 1. 문제 설정

- Teacher $f_T \in \mathcal{F}_T$는 실제 데이터 $D_n$에 표준 지도학습으로 학습되고, 학습 알고리즘은 stochastic kernel $\Delta_{f_T|D_n}$로 표현된다.
- Teacher가 만든 pseudo-dataset $\hat D_n = \{(X_i, \hat Y_i)\}$ ($\hat Y_i = f_T(X_i)$)로 student $f_S \in \mathcal{F}_S$를 학습한다. student 학습 kernel은 $\Delta_{f_S|\hat D_n}$.
- 일반화 gap 정의:
$$\mathrm{gen}_T := \mathbb{E}_{\Delta_{D_n,f_T}}[L_P(f_T) - L_{D_n}(f_T)], \quad \mathrm{gen}_S := \mathbb{E}_{\Delta_{\hat D_n,f_S}}[L_P(f_S) - L_{\hat D_n}(f_S)]$$
- 목표: $\mathrm{gen}_S$를 $\mathrm{gen}_T$와 teacher-student 프로세스 간 불일치 항으로 특징짓는 것.

---

## 2. 핵심 정의: Distillation Divergence $K_n$

$$K_n := \mathrm{KL}\left(\Delta_{\hat D_n, f_S} \,\|\, \Delta_{D_n, f_T}\right)$$

KL chain rule로 두 항으로 분해된다:

$$K_n = \underbrace{\mathrm{KL}(\Delta_{\hat D_n} \| \Delta_{D_n})}_{\text{Dataset Shift}} + \underbrace{\mathbb{E}_{\hat D_n}\left[\mathrm{KL}(\Delta_{f_S|\hat D_n} \| \Delta_{f_T|D_n})\right]}_{\text{Algorithm Shift}}$$

- **Dataset shift**: teacher가 생성한 pseudo-label 분포가 실제 데이터 분포와 얼마나 다른가.
- **Algorithm shift**: student 학습 kernel(단, teacher가 만든 $\hat D_n$을 조건으로)이 teacher 학습 kernel(실제 $D_n$을 조건으로)과 얼마나 다른가.
- 저자들은 $n$에 대해 $K_n$의 order가 주로 dataset shift 항이 지배하며, 특정 상황에서 $n$에 선형으로 자랄 수 있다고 언급한다(단, 뒤의 case study에서 최종 bound가 non-vacuous임을 보인다).

## 3. 증명된 것 (정리와 증명)

### 3.1 상한: Sub-Gaussianity + Algorithmic Stability (Theorem 1)

Teacher 일반화 gap $H(D_n, f_T) := L_P(f_T) - L_{D_n}(f_T)$가 $\sigma^2$-sub-Gaussian이면:

$$\mathrm{gen}_S \le \mathrm{gen}_T + \sigma\sqrt{2K_n}$$

- 증명은 Donsker–Varadhan(DV) variational KL 표현을 써서 $\Delta_{\hat D_n,f_S}$에서 $\Delta_{D_n,f_T}$로 measure를 바꾸고, sub-Gaussian mgf bound로 최적화(λ 최적값 대입)하는 표준 information-theoretic generalization bound 스타일 증명이다.
- **Sub-Gaussianity의 근거(Proposition 2)**: teacher 알고리즘이 $\beta$-uniformly stable이면 bounded-differences(McDiarmid) 논증으로 $\sigma^2 = \frac{n}{4}(2\beta + \frac{b-a}{n})^2$가 유도된다. $\beta = O(1/n)$인 표준적으로 안정한 알고리즘이면 $\sigma^2 = O(1/n)$이 되어 bound가 non-vacuous함을 보장한다.

### 3.2 하한: (η,c)-Central Condition (Theorem 3)

$(\eta,c)$-central condition: $\log \mathbb{E}_P[e^{-\eta H}] \le -c\eta \mathbb{E}_P[H]$.

Teacher의 일반화 gap이 이 조건을 만족하면:

$$\mathrm{gen}_S \ge c \cdot \mathrm{gen}_T - \frac{1}{\eta}K_n$$

- Sub-Gaussianity와 다르게 **$K_n$에 선형으로 의존**(제곱근이 아님)한다는 점이 다르다.
- 함의: $K_n$과 $\mathrm{gen}_T$가 둘 다 작으면 student는 teacher 성능의 $c$ 비율을 물려받는다. 반대로 $\mathrm{gen}_T$가 크더라도 distillation 과정이 큰 $K_n$을 유발하면 하한이 느슨해져서, **student가 teacher보다 더 잘 일반화하는 현상**(경험적으로 관찰돼 온 것)과 이론이 모순되지 않는다고 설명한다.
- Remark 1: sub-Gaussian이면 적절히 작은 $\eta$에서 central condition도 자동으로 성립함을 보여 두 가정이 독립적이지 않음을 명시한다.

### 3.3 Sharpness-aware bound와 tightness radius (Theorem 4, Corollary 5)

Radius-$\rho$ 랜덤 섭동 $U$에 대한 empirical/population sharpness:
$$S_D(f) := \mathbb{E}_U[L_D(f+U)] - L_D(f), \quad S_P(f) := \mathbb{E}_U[L_P(f+U)] - L_P(f)$$

$h_U(D,f) := \mathbb{E}_U[h(D,f+U)]$가 $\sigma_u^2$-sub-Gaussian, $S_{D_n}(f_T)$가 $\nu^2$-sub-Gaussian이면:

$$\mathrm{gen}_S \le \mathrm{gen}_T + \mathbb{E}[S_P(f_T)] + (\sigma_u+\nu)\sqrt{2K_n}$$

- 표준 bound $B_{std} := \mathrm{gen}_T + \sigma_0\sqrt{2K_n}$ 대비, sharpness-aware bound $B_{sh}(\rho) := \mathrm{gen}_T + \mathbb{E}[S_P(f_T)] + (\sigma_u(\rho)+\nu(\rho))\sqrt{2K_n}$을 정의.
- (A1)-(A5) 조건(bounded loss, parameter stability $\|A_T(D)-A_T(D^{(i)})\| \le \kappa/n$, global/local Lipschitz, smoothness, population curvature $\tau_{op}$) 하에서 명시적 proxy들
$$\sigma_0 = \tfrac{1}{\sqrt n}(\kappa L + \tfrac{b-a}{2}),\quad \sigma_u(\rho)=\tfrac{1}{\sqrt n}(\kappa(g_0+\alpha\rho)+\tfrac{b-a}{2}),\quad \nu(\rho)=\tfrac{1}{\sqrt n}(\tfrac{\alpha\kappa}{2}\rho+g_0\rho+\tfrac{\alpha}{2}\rho^2)$$
를 유도한다.
- $\Delta := L - g_0 > 0$(teacher 주변이 global Lipschitz 상수보다 국소적으로 평평함)일 때 **cutoff radius** $\rho_0$를 명시적으로 구해, $0<\rho<\rho_0$ 구간에서 $B_{sh}(\rho) < B_{std}$가 **증명된다** (Corollary 5). 즉 "teacher가 평평할수록 bound가 타이트해진다"는 것이 엄밀한 정리다.

### 3.4 Linear Gaussian Case Study — $K_n$의 해석 가능한 분해

Teacher를 Gibbs learner로(prior $\mathcal{N}(0,\lambda^{-1})$, posterior $q_T(W|D_n) = \mathcal{MN}(\bar W_T, I_k, \Sigma_T)$), student를 teacher posterior의 **rank-$\kappa$ 근사**(prediction space에서 최적 rank-κ projection $M^\star$)로 두는 해석적 모델이다. 노이즈 채널은 $Y_n | X_n \sim \mathcal{MN}(W^\star X_n, I_k, \nu^2 I_n)$.

최종 분해:

$$K_n \le \mathbb{E}_{D_n}\Big[\underbrace{\tfrac{1}{2\nu^2}\big(\mathrm{Bias}(D_n)+k\,\mathrm{Var}(D_n)\big)}_{\text{Teacher Prediction Error}} + \underbrace{\mathrm{Apx}(D_n)}_{\text{Student Capacity / Rank Bottleneck}} + \underbrace{\mathrm{Cov}(\Sigma_S,\Sigma_T)}_{\text{Geometry Mismatch}} + \underbrace{\mathrm{Spread}(D_n)}_{\text{Posterior Spread}}\Big]$$

각 항의 정의:
- $\mathrm{Bias}(D_n) := \|(\bar W_T - W^\star)X_n\|_F^2$, $\mathrm{Var}(D_n) := \mathrm{tr}(X_n^\top \Sigma_T X_n)$ — teacher posterior mean의 편향과 posterior 자체의 분산.
- $\mathrm{Apx}(D_n) := \lambda\,\mathbb{E}_{W_T|D_n}\|W_T(I-M^\star)\|_F^2 + \frac{\beta_T}{\nu^2}\mathbb{E}_{W_T|D_n}\|W_T(I-M^\star)X_n\|_F^2$ — **rank-κ bottleneck이 버리는 에너지**(student capacity 부족 비용).
- $\mathrm{Cov}(\Sigma_S,\Sigma_T) := \frac{k}{2}\big(\mathrm{tr}(\Sigma_T^{-1}\Sigma_S) - d + \log\frac{\det\Sigma_T}{\det\Sigma_S}\big)$ — student/teacher posterior 공분산의 기하학적 불일치(Gaussian KL 형태).
- $\mathrm{Spread}(D_n) := k\big(\lambda\,\mathrm{tr}(\Sigma_T) + \frac{\beta_T}{\nu^2}\mathrm{tr}(X_n^\top \Sigma_T X_n)\big)$ — teacher posterior 자체의 잔여 요동.

이는 **분석적으로 도출된 상한 분해**(닫힌 형태 수식 전개)이지 데이터로 측정한 값이 아니다. "체크리스트"로서: teacher bias/variance를 줄이면 dataset shift가, effective rank $\kappa$를 키우면 $\mathrm{Apx}$가, $\Sigma_S$를 $\Sigma_T$에 맞추면 $\mathrm{Cov}$가 줄어든다는 설계 지침을 제공한다. 또한 $\mathrm{Apx}(D_n)$은 $n$에 선형으로 자라지만 최종 bound는 $\sqrt{K_n/n}$ 정규화로 $O(1)$이 되어 non-vacuous함을 보인다.

## 4. 증명 vs 측정 — 이 논문의 성격

- **전부 증명(proof)이다.** Theorem 1, 3, 4와 Corollary 5, 그리고 case study의 분해식까지 모두 수학적 유도이며, appendix(약 12쪽)에 상세 증명이 실려 있다.
- **실험/수치 결과가 전혀 없다.** 실제 신경망이나 벤치마크 데이터셋에 대한 어떤 수치도, 시뮬레이션도, 표/그림도 본문에 없다. Linear Gaussian case study조차 기호적(symbolic) 전개일 뿐 숫자를 대입한 시뮬레이션이 아니다.
- Conclusion에서 저자가 스스로 명시: *"Future work will focus on ... conducting experimental validation on large-scale benchmarks to verify the correlation between $K_n$ and generalization gaps, refining the theory to close the gap between the upper and lower bounds, and designing new algorithms that explicitly minimize the derived divergence components."* 즉 **경험적 검증은 저자들도 아직 하지 않은 미래 과제**로 남겨둔 것이다.

## 6. 저자가 명시한 한계

- 논문 자체에 별도의 "Limitations" 섹션은 없으나, Conclusion에서 다음을 미해결 과제로 명시한다:
  1. **경험적 검증 부재**: $K_n$과 실제 일반화 gap의 상관관계를 대규모 벤치마크에서 확인하지 않았다.
  2. **상한-하한 gap**: 상한(제곱근 의존)과 하한(선형 의존)의 스케일링이 다르며, 이 gap을 좁히는 정교화가 남아 있다.
  3. **알고리즘 설계로의 연결 미완성**: $K_n$의 분해 항들을 명시적으로 최소화하는 학습 알고리즘은 아직 제안되지 않았다(체크리스트 수준에 머무름).
- 암묵적 한계로 지적할 만한 것: (a) 상한은 teacher 알고리즘이 **uniformly stable**해야 sub-Gaussian 정당화가 성립하는데, 실제 대규모 신경망 학습(특히 non-convex, 다단계 SGD)이 이 가정을 만족하는지는 별도로 검증되지 않는다. (b) case study는 **선형 Gaussian**이라는 매우 단순화된 세팅이며, teacher/student가 실제로는 비선형 신경망(LoRA adapter 포함)일 때 이 분해가 그대로 유지될지는 불명확하다. (c) rank-bottleneck 항 $\mathrm{Apx}(D_n)$은 "prediction-space에서 최적 rank-κ 근사"라는 이상적 구성(SVD 기반, 학습으로 도달한다는 보장 없음)에 기반한다.

## 우리 실험과의 관계

- 이 논문의 중심 대상은 **student의 일반화 gap** $\mathrm{gen}_S = \mathbb{E}[L_P(f_S) - L_{\hat D_n}(f_S)]$(population risk − pseudo-data 위의 empirical risk)이고, 우리가 측정한 것은 **LoRA adapter가 codelength로 얼마나 절약했는가**($W$)와 그중 **held-out에 전이되지 않는 몫**($\Delta W$)이다. 둘 다 "학습 데이터에 대한 성능"과 "일반화되는 성능"의 차이를 잰다는 점에서 같은 직관을 겨냥하지만, **정량적으로 같은 물건이 아니다.** $\mathrm{gen}_S$는 population loss와 (teacher가 만든) pseudo-data 위의 loss 차이인 반면, 우리의 $\Delta W$는 training CoT의 codelength 절감분에서 held-out으로 정규화한 절감분을 뺀 **초과 압축량**(bit)이다. risk-gap과 bit 단위 초과-압축량은 서로 다른 척도이며, 이 논문은 둘을 연결하는 다리를 놓지 않는다.
- 그럼에도 **구조적 대응은 분명하다.** 이 논문의 $K_n$ 분해에서 **Algorithm Shift**(student 학습 kernel과 teacher 학습 kernel의 불일치)와 case study의 **rank-bottleneck 항 $\mathrm{Apx}(D_n)$**은, "student(=우리의 LoRA)가 teacher(=긴/짧은 CoT를 생성한 원본 모델)를 rank-제약 하에서 얼마나 정확히 재현하려 하는가"라는 우리 설정과 개념적으로 가장 가깝다. 우리가 관찰한 **short CoT일수록 $\Delta W/W$ 비율이 커지는 현상**(9% → ~120%)은, 이 논문 식으로 말하면 "teacher의 정보 밀도가 낮고 student가 그것을 압축이 아니라 rank-bottleneck을 통한 암기로 흡수하는 상황"에 해당한다고 해석할 수 있다 — 짧고 정형화된 instruct 스타일 CoT는 재사용 가능한 규칙(=낮은 dataset/algorithm shift로 설명되는 일반화 가능한 성분)이 적어서, adapter가 개별 학습 예시를 그대로 저장하는 쪽으로 몰리는 것으로 볼 수 있다. 반대로 긴 reasoning CoT는 여러 문제에 공유되는 추론 패턴(=teacher process에 가까운 구조)을 담고 있어 student가 "일반화 가능한 방향"으로 압축할 여지가 커서 $\Delta W/W$가 작다는 그림과 일치한다.
- 하지만 **이 논문 자체는 $W$/$\Delta W$에 대응하는 양을 정의하지도, 실증하지도 않는다.** $K_n$과 그 분해항은 모두 **증명을 위한 상한**이며, "student가 학습 데이터의 몇 bit를 저장했는가"를 직접 측정하는 개념(우리의 $W$, 또는 2607.21351의 $\mathrm{mem}_U$/$CL(\Delta\theta)$/$W(D)$)과 달리 **memorization을 명시적인 정보량으로 분리해내지 않는다.** 따라서:
  - 우리의 측정 결과는 이 논문의 **정리를 직접 검증하거나 반증하는 실험적 증거가 될 수 없다** — 애초에 이 논문이 예측 가능한 형태의 정량적 명제($K_n$의 구체적 수치, $\rho_0$의 값 등)를 우리 세팅에서 계산할 수 있는 형태로 주지 않기 때문이다(teacher/student를 Gibbs posterior·rank projection으로 특정해야 case study 수식을 쓸 수 있는데, 실제 LLM CoT distillation은 이 가정에서 한참 벗어나 있다).
  - 다만 **정성적 동기부여 증거**로는 쓸 수 있다: "student 학습이 teacher가 제공하는 구조화된 신호를 압축·재현하는 정도(algorithm shift가 작음)와, 대신 개별 pseudo-label을 그대로 베끼는 정도(rank bottleneck을 우회한 암기)가 CoT의 종류(길고 구조적인가 vs 짧고 정형적인가)에 따라 갈린다"는 이 논문의 이론적 그림을, 우리의 bit 단위 $W/\Delta W$ 분해가 **실제 LoRA-CoT distillation에서 관측 가능한 형태로 구체화한 사례**라고 자리매김할 수 있다.
  - 후속 연구 방향으로는, 이 논문의 $\mathrm{Apx}(D_n)$(rank-bottleneck 비용)이 커질수록(=student의 effective rank/LoRA rank가 teacher 신호를 담기에 부족할수록) 우리의 $\Delta W$가 커진다는 가설을 rank sweep 실험으로 직접 검정해 볼 수 있다 — 이는 2607.21351의 rank-ladder 결과(rank를 올릴수록 쓰는 bit와 leakage가 늘어난다)와도 자연스럽게 연결된다.
