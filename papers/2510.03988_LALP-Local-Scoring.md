## TL;DR

- 여러 teacher가 만든 **정답이 모두 맞는** long CoT 후보 중 어떤 것으로 SFT할지 고르는 문제를 다룬다.
- 선행 연구 GRAPE의 기준인 **GALP**(응답 전체의 평균 log prob, student 기준)는 **짧은 단일 teacher**에서는 작동하지만, **긴 CoT + 이종 teacher** 구간에서는 순위가 **뒤집힌다**. GALP가 가장 높은 Qwen3-32B 데이터가 downstream 정확도는 **가장 나쁘다**.
- 원인 진단: (1) **granularity mismatch** — test 시점의 전체 trajectory는 학습 데이터에 잘 안 덮이지만(cos 0.760) **step은 조밀하게 덮인다**(cos 0.935). (2) **fluency trap** — 토큰 평균이라 담화/필러 토큰이 점수를 지배한다. (3) **self-conditioning** — 뒤로 갈수록 자기 문맥을 복사해 log prob이 부풀려진다.
- 제안: **LALP (Local Average Log Probability)** — 응답을 reasoning step으로 쪼개고, 각 step을 **직전 $k$개 step만 조건으로** 채점한 뒤 **step 단위로 평균**한다.
- 용도 두 가지: (1) **fine-tuning 전에** teacher 고르기, (2) mixed-teacher pool에서 프롬프트별 응답 고르기. 32B student에서 GALP 대비 **+9.4점**(0.726 vs 0.632).

## 1. 문제 설정 (Section 3)

프롬프트 $x$와 후보 응답 집합 $Y(x) = \{y^{(1)}, \dots, y^{(K)}\}$가 주어졌을 때 학습에 넣을 응답 하나 $y^*$를 고른다.

- **모든 후보의 최종 정답은 ground truth와 일치한다.** 즉 correctness 필터는 이미 끝났고, 남은 것은 *supervision quality*다.
- 형식적으로 student 파라미터 $\theta_S$를 쓰는 점수 함수 $f(y; x, \theta_S)$를 찾아, $y^* = \arg\max_{y \in Y(x)} f(y; x, \theta_S)$가 fine-tuning 후 최고 성능을 내게 하는 것이 목표다.

### Baseline: GALP (GRAPE, Zhang et al. 2025)

$$\mathrm{GALP}(y \mid x) = \frac{1}{m}\sum_{t=1}^{m} \log P_{\theta_S}(y_t \mid y_{<t}, x) \;\propto\; \log P_{\theta_S}(y \mid x)$$

$m$은 $y$의 토큰 수다. "student의 pretrained 분포에 자연스러운 응답이 배우기 쉽다"는 가설이고, forward pass 한 번이면 된다. 저자들은 이를 **12K 토큰이 넘는 long trace + 문체가 크게 다른 이종 teacher** 구간에서 stress-test한다.

## 3. 왜 실패하는가 (Section 5)

### 가설: Step-compositional Generalization

held-out test 풀이를 (i) trajectory 전체 임베딩, (ii) step별 임베딩 두 수준으로 각각 임베딩하고, **학습 세트 최근접 이웃과의 cosine similarity**를 coverage로 본다.

**Figure 2 (AIME 2025):**

| 수준 | 평균 cos | 분포 |
|---|---|---|
| Trajectory (Global) | **0.760** | range 0.68–0.83, 분산 큼 |
| Step (Local) | **0.935** | p10 = 0.89, 타이트 |

- 23% 포인트 격차. test 시점에 **전체 풀이 템플릿과 맞는 학습 예시는 거의 없지만, 국소적인 reasoning move는 거의 항상 있다**.
- AMC, GSM8K에서도 같은 경향 (Figure 7, 8).
- 정성 예시(Table 11/12): trajectory 최근접은 cos 0.68–0.72로 문제 유형부터 다르고, step 최근접은 cos 0.94–0.98로 사실상 같은 논증 move다 (Bézout, 삼각부등식, 대입 계산 등).

결론: 학습해서 전이되는 단위가 step이라면, 후보의 학습 가능성도 **국소 transition의 질**로 재야 하고, 대부분 문제 특수적인 긴 prefix 아래의 전체 likelihood로 재면 안 된다.

부록 A의 toy model(Theorem A.2)이 이를 형식화한다: 관측이 국소 쌍에만 조밀하면 learner는 인접 transition에서 $q^\star(\cdot \mid i, i+1, y) = \lambda_{i,y} p_d(\cdot \mid Y_i = y) + (1-\lambda_{i,y})u(\cdot)$로 신호를 얻지만, 비국소 쌍에서는 $q^\star(\cdot \mid i, j, y) = u(\cdot)$, 즉 **무정보 prior로 붕괴**한다. 그래서 global scoring은 신호 없는 문맥까지 평균해 버린다.

## 4. 제안 방법: LALP (Section 6)

### 4.1 Step segmentation

결정론적 문장 분할 휴리스틱을 먼저 시도했으나, 긴 추론 데이터를 다루기 위해 **GLM-4.5-Air**로 LLM 기반 분할을 채택했다. 프롬프트는 "문제와 풀이를 주고 논리적 sub-step 그룹으로 나눠 JSON으로 반환, 표현은 수정하지 말고 어떤 step도 건너뛰지 말 것" (Appendix B.1).

### 4.2 정의

응답 $y$를 $p$개 step $y = (s_1, \dots, s_p)$로 나누고, 각 step $s_i = (s_i^1, \dots, s_i^{|s_i|})$를 **프롬프트 $x$와 직전 $k$개 step만** 조건으로 채점한다.

$$\mathrm{LocalLP}(s_i) = \frac{1}{|s_i|}\sum_{t=1}^{|s_i|} \log P_{\theta_S}\!\left(s_i^t \;\middle|\; s_i^{<t},\, s_{\max(1,\,i-k):\,i-1},\, x\right)$$

$$\mathrm{LALP}(y \mid x) = \frac{1}{p}\sum_{i=1}^{p} \mathrm{LocalLP}(s_i)$$

프롬프트마다 $\mathrm{LALP}(y\mid x)$가 **가장 높은** 응답을 고른다.

GALP에 없는 두 성질:
1. **equal step weighting** — 각 reasoning move가 verbosity와 무관하게 동등하게 기여한다.
2. **local conditioning** — 각 step을 "직전 전제만으로 납득 가능한가"로 재고, 문서 전체의 유창함으로 재지 않는다.

### 4.3 Context window size (Figure 3, Figure 9)

window $k$를 각 응답에서 **사용 가능한 prefix step 수의 비율** $\alpha \in \{5\%, 25\%, 50\%, 75\%\}$로 설정해 teacher 순위를 비교한다.

- $\alpha = 5\%\text{–}25\%$: 순위가 안정적이고 downstream과 일치한다 (QwQ-32B가 최고 teacher로 식별된다).
- $\alpha$가 커지면 순위가 **GALP 쪽으로 수렴**하고, Qwen3-32B가 1위가 되는 원래의 실패 모드를 복원한다.
- 즉 **locality 자체가 이득의 원인**이다. downstream 성능 기준으로도 최적 window가 존재한다 (Figure 9).

### 4.4 비용

응답당 $p$번의 forward pass가 필요하다 (GALP는 1번). 완화 근거: (1) fine-tuning 전 일회성 전처리 비용, (2) teacher 선택은 **200개 프롬프트만으로도 817개 전체 세트의 순위를 복원**한다, (3) 서로 다른 응답의 step을 batch로 묶을 수 있다.

### 6.3 메커니즘 1: 토큰 attribution (Table 4, Figure 4)

500개 long 응답의 토큰을 범주화하고, 각 방법의 **probability mass** $\mathrm{mass}_c = \sum_{t \in c} p_t / \sum_t p_t$를 계산한다.

| Token category | GALP (mass %) | LALP (mass %) |
|---|---|---|
| Discourse / filler ("Okay", "So") | 42.3 | 18.7 |
| Math / symbols | 31.2 | 48.6 |
| Reasoning transitions ("therefore") | 12.8 | 22.4 |
| Other | 13.7 | 10.3 |

담화 토큰 42% → 19%, math+reasoning 44% → 71%로 **27%p 이동**. 저확률 토큰 안에서의 구성도 바뀐다 (Figure 4, 440개 LIMO 응답): math/symbol 비중 19.2% → 28.3%.

이론(Theorem A.3, fluency trap): style 토큰에서 $\delta$만큼 유리한 hallucinated 응답은 $m > N(\Delta+\delta)/\delta$이면 GALP에서 correct 응답을 이긴다. 반대로 LALP의 분리도는 **토큰 수 $m$이 아니라 step 수 $p$로 희석**된다 (Theorem A.4: $\mathrm{LALP}(y^{(c)}) - \mathrm{LALP}(y^{(h)}) \ge \gamma/p$). 저자 추정으로 $p \sim 100\text{–}300$ vs $m \sim$ 10K+.

### 6.4 메커니즘 2: self-conditioning (Figure 5, Section 7.4.2)

$$\mathrm{Gap}(t) = \log P_{\mathrm{global}}(y_t \mid y_{<t}, x) - \log P_{\mathrm{local}}(y_t \mid y_{t-k:t-1}, x)$$

teacher 3개 각각 약 800개 응답에서 상대 위치 bin별 평균을 낸다.

- gap이 위치에 따라 **단조 증가**한다. 응답 시작(0–10%)에서 0.7–0.85, 끝(90–100%)에서 최소 0.1, 많게는 0.3 더 증가. 응답 끝 기준 global이 local보다 **0.8–1.1 nat** 더 높은 확률을 준다.
- global LP는 위치에 따라 상승하고, local LP는 평평하다 → local은 step의 **본질적 난이도**만 반영한다.
- **Qwen3가 모든 위치에서 gap이 가장 크다.** 장황하고 반복적인 문체 때문이며, 이것이 Qwen3가 GALP 1위이면서 downstream 꼴찌인 이유다.

정성 예시:

| 예시 | 상황 | log prob | prob |
|---|---|---|---|
| "177"의 마지막 자리 "7" | 최초 계산 | −1.83 | 16.0% |
| | 검증 단계 | −0.109 | 0.4%(원문 표기) → 89.7%에 해당 |
| | 최종 답 | −0.0000399 | 99.99% |
| "1+1 is 3" 토이 | "3" 최초 | −3.01 | 4.9% |
| | "3" 재등장 | −0.02 | 97.7% |
| "1228"의 "1" | 최초 계산 | −0.33 | 71% |
| | 재인용 | −0.000069 | 99.99% |
| "come in pairs" | 최초 | −1.28 | 27% |
| | 재사용 | −0.66 | 51% |

global scoring은 **reasoning confidence**(논리적 정당성)와 **recall confidence**(앞 문맥과의 일치)를 뒤섞는다. LALP는 문맥을 자르는 것으로 둘을 분리한다.

### 6.5 메커니즘 3: 느린 학습, 더 나은 일반화 (Figure 6, Appendix C.1)

- GALP로 고른 데이터가 **training loss가 더 낮고 더 빨리 수렴**하는데도 downstream 정확도는 더 낮다.
- LALP로 고른 데이터는 반대: **global training loss는 높지만 held-out reasoning step에 대한 local NLL은 더 낮다**. (수치는 제시되지 않고 곡선/서술만 있다.)
- 저자 해석: student가 유창한 scaffolding은 쉽게 맞추지만 희소한 reasoning transition은 loss에 거의 기여하지 않는다. loss 곡선만으로 최종 성능을 판단하면 안 된다.

## 7. 한계 (저자 명시)

1. **LALP는 long-range consistency를 검증할 수 없다.** 앞 step에 오류가 있어도 그로부터 올바르게 따라오는 뒤 step은 여전히 높은 점수를 받는다. 그런 일관성이 중요한 세팅에서는 local scoring + global coherence check의 하이브리드가 필요할 수 있다.
2. (Toy model 한계, Appendix A) Markov 가정, uniform background 가정. 실제로 문맥이 무정보일 때의 default는 uniform이 아니라 **반복/self-conditioning 쪽으로 치우칠 수 있고**, 이 상보적 실패 모드는 이론이 잡지 못한다 (7.4의 경험 분석이 대신 다룬다).
3. 연산 비용: 응답당 $p$번 forward pass (GALP 대비 $p$배).

## 9. 우리 실험과의 관계

우리 실험은 **보간된 teacher 스펙트럼**에서 뽑은 CoT를 **0.5B / 1B student에 LoRA r=16**으로 distill하고, 고정된 **MATH 2,113문제** 세트에서 adapter가 흡수한 정보량 $W$(bits)와 held-out으로 전이되지 않는 몫 $\Delta W$(= memorization)를 측정한다. 핵심 발견은 teacher CoT가 student에게 예측 가능해질수록 memorization share가 **0.09 → 1.20**으로 상승하고, 두 student family의 12개 조건이 **teacher-style 라벨이 아니라 학습 전에 측정한 student-side information density(bits/token)** 위에 정렬된다는 것이다.

이 논문이 "학습 전 student-side likelihood로 예측한다"는 자리를 이미 차지하고 있는가? — **부분적으로 그렇다. 다만 예측 대상이 다르다.**

### (a) 점수는 학습 전 student에서 계산되는가? 무엇을 소비하는가?

**예. 완전히 pre-training(pre-SFT) student에서 계산된다.**

- 근거: Section 7.1 "an effective scoring rule should predict the best teacher using only the **pre-trained student**"; "For each teacher, we compute the average GALP and LALP of its responses **under the pre-trained student**, then fine-tune the student on that teacher's dataset and measure downstream accuracy." Table 1/14 캡션도 "terciles by the **pre-SFT student's** global average log probability". Table 9의 GALP/LALP 열이 학습 전 점수, AVG 열이 학습 후 정확도다.
- **소비하는 것**:
  1. **Teacher가 생성한 응답 텍스트** $y$ (LIMO 프롬프트에 대한 정답 검증된 long CoT). 이것을 GLM-4.5-Air가 step $s_1,\dots,s_p$로 분할한다.
  2. **Student의 token log-prob** $\log P_{\theta_S}(\cdot)$. student forward pass만 필요하고 **teacher logits나 teacher 확률은 전혀 쓰지 않는다** (response-level KD 계열).
  3. **Context window**: 프롬프트 $x$ + 직전 $k$개 **step**. $k$는 각 응답의 가용 prefix step 수의 비율 $\alpha \in \{5\%,25\%,50\%,75\%\}$로 지정하며, $\alpha = 5\text{–}25\%$에서 순위가 안정적이다. 즉 우리처럼 고정 토큰 창이 아니라 **응답 길이에 비례하는 step 단위 창**이다.
- **우리와의 차이**: 우리의 bits/token은 student가 teacher 텍스트에 대해 갖는 평균 surprisal을 **전체 시퀀스에 대해** 재는 값이고, LALP는 같은 재료(student log-prob on teacher text)를 **step 평균 + 국소 조건**으로 재구성한 값이다. 재료는 같고 집계 방식이 다르다. **따라서 "학습 전 student-side likelihood 측정" 자체는 이 논문이 이미 점유하고 있다.** 우리 기여를 "측정 시점/재료의 신규성"으로 주장하면 안 된다.

### (b) 무엇을 예측하는가? memorization/generalization에 대해 말하는가?

**downstream 정확도만 예측한다. 학습 데이터의 memorization/generalization에 대해서는 아무것도 예측하지 않는다.**

- 예측 대상은 두 가지뿐이다: (1) **teacher 순위** — LALP 순위 QwQ > DeepSeek-R1 > Qwen3가 downstream AVG 순위(0.719 > 0.659 > 0.637)와 일치, (2) **프롬프트별 응답 선택 후의 벤치마크 평균** (0.726 vs 0.632).
- memorization이라는 단어도, 학습 데이터의 재현 여부도, 일반화 gap의 정량화도 없다. 가장 가까운 것이 Section 7.4.3의 "slower learning yet better generalization"인데, 이는 **training loss 곡선 + downstream 정확도**의 불일치를 서술한 *사후 해석*이지 측정된 memorization 양이 아니다.
- **우리 자리는 여기가 비어 있다.** LALP는 "이 데이터를 쓰면 정확도가 몇 점 나온다"를, 우리는 "이 데이터를 쓰면 adapter가 몇 bit를 삼키고 그 중 몇 %가 held-out으로 전이되지 않는다"를 예측한다. 후자는 이 논문에 대응물이 없다.

### (c) train vs held-out, verbatim 재현, bits/codelength, adapter 수준 양을 재는가?

| 항목 | 이 논문 | 비고 |
|---|---|---|
| train vs held-out 행동 | **부분적으로 있음** | Figure 2: held-out test 풀이의 학습셋 최근접 이웃 coverage를 trajectory(0.760) vs step(0.935)로 측정. Section 7.4.3: "lower local NLL on **held-out reasoning steps**" — 단, **수치 없이 서술만**이고 곡선 비교뿐이다. 이는 임베딩 유사도이지 손실/정보량 기반 train–held-out gap이 아니다. |
| verbatim 재현 | **없음** | 학습 데이터를 student가 그대로 뱉는지 측정하지 않는다. 다만 **self-conditioning gap**(Eq. 4)이 인접 개념이다 — 응답 *내부*에서 같은 값/표현이 재등장할 때 log prob이 −1.83 → −0.0000399로 치솟는 현상. 이는 **학습 전 student가 teacher 텍스트를 읽으며 자기 문맥을 복사하는 효과**이지, 학습된 모델이 학습 데이터를 암기해 재현하는 현상이 아니다. 혼동하지 말 것. |
| bits / codelength | **없음** | 모든 점수가 **nat 단위 log-prob의 토큰 평균 또는 step 평균**이다. bit로 변환하지 않고, 합산 codelength(= 총 정보량)를 만들지 않는다. 애초에 길이 정규화를 하기 때문에 codelength 해석과는 반대 방향의 양이다. |
| adapter 수준 양 | **전혀 없음** | LoRA/adapter/PEFT가 논문에 등장하지 않는다. 파라미터 변화량, rank, spectral 분석 같은 가중치 수준 양도 없다. gradient 기반 방법(LESS, influence function)은 "비싸서 안 쓴다"고 related work에서 배제한다. |

### (d) teacher 출력 문체를 연속 축으로 변화시키는가?

**아니다. 이산 라벨 3개다.**

- teacher pool은 DeepSeek-R1 / Qwen3-32B / QwQ-32B라는 **서로 다른 모델 3개**이고, 이들이 "verbosity, self-reflection patterns, stylistic scaffolding에서 크게 다르다"고만 서술된다. 문체를 매개변수화하거나 보간하지 않는다.
- 이 논문에서 **연속적으로 변화시키는 유일한 축은 scorer의 window 비율 $\alpha$**($5\%\to75\%$)이고, 이는 teacher 쪽이 아니라 **측정 쪽** 축이다.
- **우리의 보간 teacher 스펙트럼은 이 논문에 대응물이 없다.** 우리는 문체를 연속 축으로 두고 그 위에서 memorization share가 0.09 → 1.20으로 단조 증가함을 보이는 반면, 이 논문은 3점 이산 비교에서 순위 반전만 보인다.
- 다만 **정성적으로는 같은 방향을 가리킨다**: Qwen3-32B가 GALP 최고(student에게 가장 예측 가능)이면서 self-conditioning gap도 최대이고 downstream은 최악이다. 이는 "teacher CoT가 student에게 예측 가능해질수록 학습 성과가 나빠진다"는 우리 곡선의 **거친 3점 버전**이며, 우리 결과의 독립적 방증으로 인용할 수 있다. 단 이 논문은 그 이유를 memorization이 아니라 *fluency trap + self-conditioning*으로 설명한다.

### (e) LoRA/PEFT를 쓰는가?

**아니다.** LLaMA-Factory 기반 SFT이고 하이퍼파라미터 표(Table 6)에 batch, grad accum, lr, epochs, warmup, bf16만 있을 뿐 rank, alpha, target module 같은 PEFT 항목이 없다. 본문·부록 어디에도 LoRA / adapter / PEFT / low-rank라는 단어가 없다. (4×A100으로 32B를 10–15 epoch 돌렸다는 서술은 물리적으로 의아하지만, 논문이 PEFT를 주장하지 않으므로 **full fine-tuning으로 기술된 것**으로 읽어야 한다.)

### 정리: 우리 novelty가 남아 있는 부분

**점유당한 것 (주장하면 안 되는 것):**
- "학습 전 student-side likelihood 측정으로 distillation 데이터의 downstream 결과를 예측한다" — Section 7.1이 정확히 이것이다. teacher 선택을 fine-tuning 없이 예측하는 것도 이미 했다 (200 프롬프트면 충분하다는 효율성 주장까지).
- "전체 시퀀스 likelihood는 문체에 속아 잘못된 순위를 준다" — GALP 실패 분석이 이것이다.

**남아 있는 것 (우리 기여):**
1. **예측 대상이 정확도가 아니라 memorization share** — $W$, $\Delta W$를 bits로 분해하는 회계 자체가 없다.
2. **bits/codelength 프레이밍** — 이 논문은 길이 정규화된 nat 평균만 쓴다. 총 정보량 개념이 없다.
3. **adapter 수준 측정** — LoRA r=16이 흡수한 용량이라는 단위가 없다.
4. **연속 teacher 축** — 이산 teacher 3개 vs 우리 보간 스펙트럼.
5. **소형 student(0.5B/1B)** — 이 논문의 최소 student는 7B이고, 주 결과는 32B다. 용량 제약이 memorization을 지배하는 구간을 다루지 않는다.
6. **관계의 방향** — LALP는 student-side likelihood가 **높을수록 좋다**(단, 국소 조건 하에서)는 선택 규칙이다. 우리는 student-side 예측 가능성이 높을수록 **memorization이 커진다**고 본다. 두 진술은 모순이 아니라 같은 현상의 다른 층위지만(그들의 GALP 실패가 우리 방향과 일치), **"왜 예측 가능한 CoT가 나쁜가"에 대한 메커니즘을 memorization으로 특정한 것은 우리 쪽이다.** 이 논문은 fluency trap / self-conditioning으로 설명하고 멈춘다.

**실무적으로 할 일:**
- 이 논문을 related work의 "학습 전 student-side scoring" 계보(GRAPE → LALP)에 넣고, 우리 기여를 "같은 재료로 **다른 양**(bits, memorization share)을 예측한다"로 위치시킨다.
- 우리 bits/token 지표는 집계 방식이 GALP에 가깝다(전체 시퀀스). 이 논문이 보인 self-conditioning 효과(응답 후반부에서 global이 local보다 0.8–1.1 nat 높음)는 **우리 bits/token이 긴 CoT에서 과소평가될 수 있음을 시사하는 실질적 경고**다. LALP 방식의 국소 창으로 bits/token을 다시 재서 12개 조건의 정렬이 유지되는지 확인해 볼 가치가 있다 — 유지되면 우리 결과가 집계 방식에 강건하다는 추가 증거가 된다.
