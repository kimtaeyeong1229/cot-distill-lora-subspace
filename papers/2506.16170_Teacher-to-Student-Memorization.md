---

## TL;DR

- Instruction fine-tuning된 큰 teacher를 여러 지식 증류(KD) 방법으로 작은 student에 옮길 때, **증류가 표준 fine-tuning(SFT)보다 memorization을 일관되게 줄인다**는 것을 GPT-2 계열로 실증한다.
- memorization은 Carlini et al. (2023)의 verbatim-recall 정의를 instruction-following용으로 옮겨, **greedy decoding으로 학습 응답을 정확히(50토큰 이상) 재생하는 비율**로 측정한다.
- 4가지 학습 방식(SFT, word-level KD, sequence-level KD, MiniLLM의 reverse-KL KD)을 GPT-2 1.5B(teacher) → 760M/340M/120M(student)에 적용해 비교.
- 헤드라인: SFT가 가장 높은 memorization과 가장 높은 train-ROUGE를 보이고, **RKLD(MiniLLM)가 모델 크기에 무관하게 가장 낮은 memorization**(0.060~0.090)을 달성하면서 test-ROUGE는 유지한다.

---

## 1. 문제의식

- 기존 memorization 연구(Carlini et al. 2021, 2023)는 **사전학습 모델과 원 학습 데이터**에 집중했다. fine-tuning은 데이터가 작고 민감한 경우(의료 기록, 사내 데이터 등)가 많아 memorization 위험이 더 크지만 잘 다뤄지지 않았다.
- 지식 증류(KD)는 원래 계산량·모델 크기를 줄이려는 기법인데, **증류가 memorization에 어떤 영향을 주는지는 그동안 아무도 체계적으로 보지 않았다.**
- 이 논문은 "fine-tuned teacher → 여러 KD 방법 → 작은 student"라는 파이프라인에서 memorization이 어떻게 달라지는지를 처음으로 정량 비교한다.

---

## 2. 방법론

### 2.1 Memorization 정의 (Algorithm 1)

instruction-context-response 튜플 $(p, c, s)$에 대해, 모델을 $(p, c)$로 프롬프트하고 greedy decoding으로 생성했을 때 생성 결과가 $s$와 **정확히 일치**(길이 $k$=$s$의 길이만큼)하면 "암기"로 센다. 데이터셋 전체에 대한 memorization fraction $M \in [0,1]$을 계산한다(암기 개수 / 전체 개수).

### 2.2 비교한 4가지 학습 방식

| 방법 | 핵심 |
|---|---|
| **SFT** (baseline) | teacher 없이 정답 응답으로 직접 next-token loss 학습 |
| **Word-level KD (WL-KD)** | 각 위치에서 teacher의 토큰별 soft 확률분포를 student가 모사(forward KL 형태) |
| **Sequence-level KD (SeqKD)** | teacher의 beam-search 출력 시퀀스 전체를 student가 맞히도록 학습 |
| **Reverse KLD (RKLD, MiniLLM)** | student→teacher의 reverse KL을 최소화(Gu et al. 2024의 MiniLLM 절차 따름), overconfidence(=암기)를 구조적으로 억제 |

### 2.3 평가 지표

- **Memorization Fraction**: Algorithm 1, $k=50$, 학습셋에서 무작위 추출한 3,000개 예시로 측정.
- **ROUGE-1/2/L**: train 500개·test 500개에 대해 생성 결과와 정답을 비교. **train ROUGE가 높으면서 memorization fraction도 높으면 verbatim copying**의 근거로 해석.

---

## 3. 실험 설정

- **모델**: GPT-2 계열. teacher = GPT-2 1.5B (databricks-dolly-15k 10,000개로 fine-tune). student = GPT-2 760M / 340M / 120M.
- **데이터**: DollyEval (databricks-dolly-15k). teacher fine-tuning에 10,000개 사용, 나머지 5,000개 중 500개를 test-ROUGE 평가용으로 샘플링.
- teacher를 위 4가지 방법(SFT는 student에 직접, KD/SeqKD/RKLD는 teacher 지도)으로 각 student 크기에 증류.

## 4. 결과

### Table 1 — Memorization Fraction

| Model | Params | Technique | Memorization Fraction |
|---|---|---|---|
| GPT2 | 1.5B | SFT (teacher) | 0.654 |
| | 760M | SFT | 0.523 |
| | 360M | SFT | 0.433 |
| | 120M | SFT | 0.330 |
| | 760M | KD | 0.472 |
| | 360M | KD | 0.140 |
| | 120M | KD | 0.100 |
| | 760M | SeqKD | 0.315 |
| | 360M | SeqKD | 0.134 |
| | 120M | SeqKD | 0.129 |
| | 760M | RKLD | 0.090 |
| | 360M | RKLD | 0.075 |
| | 120M | RKLD | 0.060 |

- **크기와 암기가 비례**: teacher(1.5B)가 가장 크게 암기하고, 같은 학습법 내에서는 모델이 작을수록 memorization이 낮다.
- **SFT가 항상 최고 memorization**: teacher 정답을 직접 학습하는 SFT가 모든 크기에서 KD 계열보다 높다.
- **RKLD(MiniLLM)가 최저**: 120M 0.060, 340M 0.075, 760M 0.090 — reverse KL이 overconfidence를 구조적으로 억제하는 목적과 부합.
- KD, SeqKD도 SFT보다는 낮지만 RKLD보다는 높다(예: 760M 기준 KD 0.472, SeqKD 0.315 vs RKLD 0.090).

### ROUGE (Table 2/3/4 요약, R-1 기준)

| Model | Technique | Train R-1 | Test R-1 |
|---|---|---|---|
| 1.5B | SFT (teacher) | 0.88 | 0.33 |
| 760M | SFT | 0.78 | 0.31 |
| 760M | KD | 0.73 | 0.34 |
| 760M | SeqKD | 0.69 | 0.32 |
| 760M | RKLD | 0.45 | 0.36 |
| 120M | SFT | 0.67 | 0.25 |
| 120M | KD | 0.65 | 0.28 |
| 120M | SeqKD | 0.75 | 0.27 |
| 120M | RKLD | 0.46 | 0.30 |

(R-2, R-L도 같은 경향: 부록 Table 3, 4 참조.)

- SFT는 train ROUGE가 가장 높고 test ROUGE는 상대적으로 낮음 — train set에 대한 **직접적 패턴 암기**의 지표.
- RKLD는 train ROUGE가 가장 낮으면서 test ROUGE는 오히려 KD/SeqKD/SFT보다 높거나 비슷 — **train-test 격차가 가장 작다** = 일반화에 더 가깝고 암기에 덜 의존.
- KD, SeqKD는 SFT보다 낮은 train ROUGE를 보이면서 test ROUGE는 SFT와 비슷하거나 더 나음.

## 5. 한계 (저자가 명시)

- **단일 데이터셋(DollyEval)**만 사용 — 계산 자원 제약으로 다양한 태스크의 memorization 양상을 포착하지 못했을 수 있음.
- memorization fraction은 **고정된 50-token window**로만 측정 — 다른 시퀀스 길이에서는 다른 결과가 나올 수 있음.
- GPT-2 계열에 국한 — 다른 아키텍처로의 일반화는 향후 과제.
- perplexity, BLEU 등 추가 지표 없이 memorization fraction과 ROUGE만 사용.
- exact-match 기반 verbatim 정의라 **implicit memorization**(정확히 재생하진 않지만 정보가 새는 경우)은 다루지 않음 — 저자도 Ethical Considerations에서 "복잡한 추출 기법에는 여전히 취약할 수 있다"고 인정.

## 우리 실험과의 관계

이 논문은 "**distillation이 standard fine-tuning보다 memorization을 줄인다**"는 것과 "**KD 방법마다 그 정도가 다르다**"(RKLD < SeqKD ≈ KD < SFT)는 것을 verbatim-recall 비율(0~1의 fraction)이라는 거친 지표로 보여준다. 우리 실험(long-CoT ↔ short-CoT teacher 스펙트럼을 Qwen2.5-0.5B-Instruct에 LoRA r=16으로 증류하고 W/ΔW를 bit 단위로 측정)과 맞닿는 지점은 **"학습 방식이 memorization 비중을 결정한다"**는 결론 자체다 — 이 논문의 "SFT > KD > RKLD" 순서와, 우리가 본 "short-CoT teacher(few bits, ~100% ΔW)" vs "long-CoT teacher(27배 많은 bits, ΔW 9%)"는 같은 방향(teacher/학습 신호의 성격이 암기율을 좌우)을 가리킨다.

다만 이 논문이 다루지 않는 것, 즉 우리 실험이 메꾸는 공백은 명확하다.

- **teacher output style을 연속적인 축으로 보지 않는다.** 이 논문은 KD *방법*(SFT/WL-KD/SeqKD/RKLD)을 바꿀 뿐, teacher가 생성하는 응답의 *스타일*(길고 탐색적인 R1식 CoT ↔짧고 직접적인 instruct식 CoT)을 축으로 삼지는 않는다. teacher 응답 자체의 성격이 암기량을 27배 가른다는 우리 발견은 이 논문의 스코프 밖이다.
- **PEFT/LoRA adapter를 다루지 않는다.** 이 논문의 student는 전부 full fine-tuning(또는 full 증류)된 GPT-2이고, adapter 용량이라는 제약 자체는 등장하지 않는다.
- **memorization을 bit 단위로 재지 않는다.** 이 논문의 memorization fraction은 "0/1 verbatim match의 비율"이라는 이산적·거친 지표이고, WL-KD의 soft label처럼 애초에 정확한 verbatim match가 잘 나오지 않는 방법에서는 지표가 무엇을 반영하는지 애매하다. 반면 우리는 압축 기반(codelength) bit 측정으로 "얼마나 많은 정보가 흡수됐는지(W)"와 "그중 얼마가 암기인지(ΔW)"를 분리해서 비율까지 낸다 — 이 논문이 "SFT가 더 많이 외운다"까지만 말한다면, 우리는 "얼마나 더", "흡수된 것 중 몇 %가 암기인지"까지 답한다.
