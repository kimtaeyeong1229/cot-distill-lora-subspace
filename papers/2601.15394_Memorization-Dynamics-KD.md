## TL;DR

- **KD(지식 증류)로 학습한 student는 같은 크기의 일반 fine-tuning baseline보다 학습 데이터를 훨씬 덜 암기한다.** Pythia/FineWeb에서 0.07% vs 0.17% (약 2.4× 감소), 데이터셋·아키텍처를 바꿔도 같은 방향이다.
- 게다가 **성능은 더 좋다.** student의 validation loss/PPL이 baseline보다 낮다. 즉 "암기를 줄인 대가로 성능을 잃는" 트레이드오프가 아니다.
- 암기는 **확률적이 아니라 결정론적**이다. 특정 예시들이 seed·모델 크기를 넘어 반복적으로 암기되며(=**easy-to-memorize**), student 암기의 **95.7%**가 이 집합에 속한다. 이들은 **zlib entropy와 perplexity가 모두 낮은** 뚜렷한 클러스터를 이룬다.
- 그래서 **학습 전에 예측 가능하다.** teacher PPL + zlib entropy만으로 로지스틱 회귀가 AUC **0.9998**, Recall **1.0000**을 낸다. 예측된 예시를 빼고 증류하면 암기가 **706 → 4개(99.4% 감소)**.
- **왜 줄어드는가**: CE는 1.4B가 자신 없어 하는(high entropy) 시퀀스에도 높은 확률을 강제해 **forced memorization**을 만든다. KL은 student가 teacher를 못 따라갈 때 **납작한 분포를 출력하도록 허용**하므로 암기가 발생하지 않는다.
- **soft vs hard**: 전체 암기율은 0.07%로 동일하고 암기 집합의 70%가 겹치지만, **hard(sequence-level) distillation은 teacher에게서만 물려받은 difficult 예시를 2.7배 더 많이 상속**한다. CoT distillation처럼 teacher 생성 시퀀스로 CE 학습하는 방식이 여기에 해당한다.

## 1. 문제의식

- KD는 성능·효율뿐 아니라 **프라이버시 방어 수단**으로도 자주 인용된다 (Papernot et al. 2018; Tang et al. 2022). teacher의 학습 데이터를 추출 공격으로부터 보호한다는 주장이다.
- 그런데 memorization/데이터 추출은 **pre-training과 fine-tuning에서만** 집중적으로 연구되었고, **전형적인 KD 파이프라인(KL loss로 teacher 분포를 모사)에서의 동역학은 거의 알려진 바가 없다.**
- 선행 연구도 엇갈린다. Dankers and Raunak (2025)은 기계번역 sequence-level distillation에서 **student가 teacher의 암기를 대부분 물려받는다**고 보고했다. 이 논문은 logit-level KD에서 정반대 결과를 얻는다.
- 그래서 이 논문은 **teacher / baseline / student 세 모델 전체를 같은 척도로 추적**하며, 암기의 **양**뿐 아니라 **어떤 종류의 예시가** 암기되는지를 함께 본다.

## 2. 정의와 측정 방법

### 2.1 세 모델

| 기호 | 정의 |
|---|---|
| $M_{teacher}$ | 큰 모델. 데이터셋 $D$에 대해 cross-entropy로 fine-tuning |
| $M_{student}$ | 작은 모델. 같은 $D$에서 teacher의 logit 분포를 KL로 모사 |
| $M_{baseline}$ | student와 **같은 크기**의 모델을 같은 $D$에서 **독립적으로 CE fine-tuning** |
| $D$ | 세 모델 모두가 쓰는 동일한 학습 데이터셋 |

핵심 통제 장치는 $M_{baseline}$이다. student의 암기량을 "같은 크기, 같은 데이터, 다른 loss"와 직접 비교할 수 있게 한다.

### 2.2 Distillation objective

forward KL divergence (Hinton et al. 2015):

$$\mathcal{L}_{KD} = T^2 \sum_{i=1}^{|V|} P^\tau_{teacher}(i)\,\log\frac{P^\tau_{teacher}(i)}{P^\tau_{student}(i)}$$

$$P^\tau(i) = \mathrm{softmax}\!\left(\frac{z_i}{T}\right) = \frac{\exp(z_i/T)}{\sum_{j=1}^{|V|}\exp(z_j/T)}$$

- $z_i$는 vocab token $i$의 pre-softmax logit, $T$는 temperature이며 주 실험에서 $T = 2.0$이다.

### 2.3 Memorization 지표 — Discoverable Memorization

Nasr et al. (2023)의 정의를 그대로 채택한다. 학습 시퀀스 $x \in D$를 prefix $x_{1:k}$와 suffix $x_{k+1:L}$로 나누고, **$k = 50$, $L = 100$**으로 둔다. greedy decoding 함수 $G(\cdot)$가 $L-k$개 토큰을 생성했을 때

$$G(x_{1:k}) = x_{k+1:L}$$

가 **정확히 일치**하면 그 예시를 memorized로 분류한다. 이 평가를 학습 데이터 **100만 개 예시 전부**에 대해 수행한다.

> 즉 이 논문의 memorization은 **예시 단위 이진 판정 → 비율(%)**이다. bit 단위 codelength가 아니다.

### 2.4 easy-to-memorize를 설명하는 내재 속성

- **zlib entropy**: 토큰 시퀀스를 텍스트로 디코딩한 뒤 zlib 압축 표현의 **바이트 길이**를 잰다. 디코딩이 tokenizer에 의존하므로 **본질적으로 모델 의존적 지표**라고 저자들이 명시한다.
- **perplexity**: baseline / teacher 각각에 대해 계산.
- 이 데이터(FineWeb)에는 sequence-level 중복이 없으므로(Penedo et al. 2024), 선행 연구가 지목한 **duplication은 원인이 아니다.** 대신 텍스트의 압축 가능성과 예측 용이성이 원인이다.

### 2.5 Shannon entropy / log-probability 분석 (Section 5)

암기 여부를 가르는 메커니즘을 보기 위해, 각 예시의 **50-token suffix**에 대해 두 값을 계산한다.

$$H_t(x) = -\sum_{v \in V} p_\theta(v \mid x_{<t})\log p_\theta(v \mid x_{<t})$$

$$\bar{H}_\theta(x) = \frac{1}{K}\sum_{t=T-K}^{T-1} H_t(x), \qquad K = 50$$

여기에 시퀀스 log-probability(confidence)를 함께 놓고 산점도를 그린다.

### 2.6 Hard(sequence-level) distillation (Section 6)

$D$의 각 예시에 대해 teacher에 **처음 50 토큰**을 넣고 greedy로 **206 토큰**을 생성해 길이 $T = 256$의 합성 데이터셋 $D_{hard}$를 만든다. student는 Pythia 1.4B base에서 시작해 $D_{hard}$에 대해 CE로 학습한다.

$$\mathcal{L}_{hard}(\theta) = -\mathbb{E}_{\hat{x}\sim D_{hard}}\left[\sum_{t=1}^{T}\log P_\theta(\hat{x}_t \mid \hat{x}_{<t})\right]$$

**memorization inheritance** 정의: teacher와 student가 암기했지만 **baseline은 암기하지 않은** 예시.

## 3. 실험 설정

| 항목 | 값 |
|---|---|
| 주 설정 | Pythia 12B (teacher) → Pythia 1.4B (student / baseline), FineWeb |
| 데이터 $D$ | FineWeb **2025년 7월 Common Crawl dump**에서 **100만 예시**, 시퀀스 길이 **256 토큰** |
| 추가 모델 패밀리 | OLMo-2 (7B → 1B), Qwen-3 (8B → 1.7B) |
| 추가 데이터셋 | WikiText-103, Nemotron-CC-v2 (합성) |
| KD temperature | $T = 2.0$ (온도 sweep은 Figure 2) |
| Learning rate | $5\times10^{-5}$, cosine decay |
| Epochs | teacher **3 epochs**; student·baseline **4 epochs (Pythia)** / **5 epochs (OLMo-2, Qwen-3)** |
| Compute | student와 baseline은 **동등한 연산 예산** |
| Seed | baseline·student 각각 **3 run**(데이터 순서 + 초기화 변경, 하이퍼파라미터 고정), 암기 집합은 union으로 보고 |
| Hard distillation 평가 | LAMBADA, Winogrande (lm-eval-harness, Gao et al. 2024) — 합성 데이터로 학습한 student에 held-out PPL이 불공정하므로 downstream task 사용 |

### 4.3 일부 예시는 본질적으로 외우기 쉽다 (Section 3.2)

- **모델 크기 계층성**: Pythia 1B가 암기한 것의 **96%**가 1.4B baseline에도 남고, 12B teacher는 1.4B baseline 암기 집합의 **약 80%**를 포함한다.
- **seed 일관성 (Figure 3)**: baseline은 3개 독립 run 전부에서 동일한 핵심 집합을 암기한다. 반대로 **(three, zero) 셀에 494개** — baseline이 3회 모두 암기했지만 student는 한 번도 암기하지 않은 예시.
- **student는 easy만 외운다**: student 암기 706개 중 **676개(95.7%)**가 teacher·baseline이 함께 암기한 예시다. 동시에 teacher·baseline이 모두 암기한 **696개**를 student는 암기하지 못한다.
- **내재 속성 (Figure 5)**: easy-to-memorize 예시는 무작위 25,000개 대조군 대비 **zlib entropy와 baseline perplexity가 모두 뚜렷하게 낮은** 밀집 클러스터를 형성한다.

**Appendix A.4.1 — 다른 모델/데이터셋에서의 비율**

| 설정 | student 암기 중 easy-to-memorize 비율 | teacher로부터의 inheritance 비율 |
|---|---|---|
| Pythia (WikiText) | 88% | 9% |

### 4.4 모든 모델이 같은 easy 예시를 외우는 것은 아니다 (Section 3.2.1)

- OLMo-2 1B, Qwen-3 1.7B를 Pythia 1.4B baseline과 **완전히 같은 데이터·하이퍼파라미터**로 학습시켰더니, **패밀리 간 암기 집합 overlap이 0**이다. 12B / 7B / 8B 대형 모델 쌍에서도 **zero overlap**.
- 그런데 데이터 복잡도 인식은 거의 동일하다. zlib entropy(bits per token)의 Pearson 상관:

| 쌍 | Pearson $r$ |
|---|---|
| Pythia vs Qwen-3 | 0.95 |
| Pythia vs OLMo-2 | 0.96 |
| Qwen-3 vs OLMo-2 | 0.99 |

- 즉 **"어떤 예시가 쉬운가"에는 모두 동의하지만, "그중 무엇을 실제로 외울지"는 각자 다르다.** Figure 6의 pairwise perplexity 비교에서 한 모델이 외운 예시는 다른 모델에서 **높은 perplexity** 영역에 놓인다. 저자들은 이를 tokenization·attention bias 등 **아키텍처 고유의 inductive bias** 탓으로 본다.

### 4.5 학습 전에 암기를 예측할 수 있다 (Section 4)

- student가 암기한 **706개**를 positive, 나머지를 negative로 두고 로지스틱 회귀를 학습. 비율 **1:3**, 테스트 30%, **100 trial**(매 trial마다 negative 재샘플링).

| Classifier | Features | AUC-ROC | Recall | Precision |
|---|---|---|---|---|
| #1 | teacher PPL + baseline PPL + teacher–baseline KLD + zlib entropy | 0.9997 ± 0.0005 | 1.0000 ± 0.0000 | 0.9917 ± 0.0059 |
| #2 | **teacher PPL + zlib entropy만** | **0.9998 ± 0.0005** | 1.0000 ± 0.0000 | 0.9940 ± 0.0054 |

→ **baseline 모델 없이도** 예측이 된다는 점이 실무적으로 중요하다.

**Table 4 — 표준화 회귀 계수 (Pythia / FineWeb, 100 trial 평균)**

| Feature | Coefficient |
|---|---|
| Teacher PPL | −0.3341 ± 0.1228 |
| Baseline PPL | −0.4010 ± 0.1417 |
| **zlib Entropy** | **−4.5001 ± 0.1324** |
| Teacher–Baseline KLD | −1.0579 ± 0.1664 |

모든 feature의 계수가 음수 = **값이 낮을수록 암기된다.** zlib entropy가 압도적 1위이며, OLMo-2(−4.4637), Qwen-3(−5.4524)에서도 같다. 단, **Pythia/WikiText에서는 Teacher PPL(−2.7531)이 1위**이고 zlib은 −2.0809로 순위가 바뀐다.

**암기 예시 제거 실험 (Section 4.2)**: $D_{clean} = D \setminus \hat{D}_{mem}$으로 다시 증류하면 **새로 4개**가 암기되지만 총량은 **706 → 4개, 99.4% 감소**한다.

### 4.6 왜 KD가 암기를 줄이는가 (Section 5, Figure 8)

baseline·teacher는 암기했지만 student는 암기하지 않은 **696개** 예시를 (log-probability, average Shannon entropy) 평면에 놓으면 세 가지 거동이 나온다.

| 모델 | 위치 | 해석 |
|---|---|---|
| Teacher (12B) | 높은 log-prob, **낮은 entropy** | 진짜로 확신함. 자연스러운 암기 |
| Baseline (1.4B) | 높은 log-prob, **높은 entropy** | **Forced memorization** — 용량이 없어 불확실한데도 CE가 ground truth에 높은 확률을 강제 |
| Student (1.4B) | **낮은 log-prob**, 높은 entropy | 같은 1.4B 용량이라 여전히 불확실하지만, KL은 **납작한 분포 출력을 허용**하므로 암기가 발생하지 않음 |

student가 실제로 암기한 예시(Figure 8 Right)는 **teacher와 겹치는 낮은 entropy 영역**에 몰린다. 즉 student는 **높은 확신으로 배울 만큼 단순한 것만** 외우고 나머지 high-entropy noise는 걸러낸다.

**Appendix A.6 — student 암기 vs baseline 전용 암기 구분 (MIA AUC)**

| Feature | AUC |
|---|---|
| Teacher perplexity | 0.745 |
| Baseline perplexity | 0.754 |
| **Teacher–Student KLD loss** | **0.855** |

### 4.7 Soft vs Hard distillation (Section 6)

**Utility (같은 예산·같은 LR)**

| Model | LAMBADA PPL | LAMBADA Acc | Winogrande Acc |
|---|---|---|---|
| $M_{baseline}$ | 9.41 | 51.85% | 55.72% |
| $M_{student\_hard}$ | **6.43** | **56.65%** | **57.46%** |

**Memorization**

| 항목 | 값 |
|---|---|
| hard-distilled student 암기율 | **0.07%** (soft와 동일, baseline 0.17%) |
| soft ∩ hard overlap | hard student 암기의 **약 70%**가 soft student에도 |
| hard student가 외운 easy-to-memorize | **90%** (teacher·baseline 모두 암기 — Figure 11에서 **673개**) |
| hard 전용 암기 (soft·baseline 둘 다 없음) | **46개**, 그중 **80%**를 teacher가 암기 |
| **teacher-only inheritance** | hard **50개** vs soft **18개** → **2.7×** |

→ 총량은 같지만 **위험의 질이 다르다.** soft distillation은 teacher가 독점적으로 암기한 *difficult* 예시를 걸러내는 반면, **hard distillation은 그것을 그대로 물려받는다.** teacher의 full logit에 접근할 수 없는 black-box API 증류가 정확히 이 경우다.

- baseline 암기 2,785개 중 **2,117개(76%)**를 teacher도 암기(=easy-to-memorize). 그 2,117개 중 student가 암기한 것은 **361개**뿐. student만 암기하고 teacher·baseline 모두 암기하지 않은 예시는 **92개**.

## 5. 저자가 밝힌 한계 / 유보 사항

별도의 Limitations 절은 없고, 본문에 흩어져 명시된 유보 사항은 다음과 같다.

- **zlib entropy는 모델 의존적 지표다.** 토큰 시퀀스를 텍스트로 디코딩하는 과정이 모델별 tokenizer에 의존하므로, 서로 다른 패밀리 간 값을 그대로 비교하기 어렵다 (Section 3.2).
- **easy-to-memorize 집합은 패밀리 밖으로 전이되지 않는다.** Pythia / OLMo-2 / Qwen-3 사이 overlap이 0이므로, 한 모델에서 학습한 암기 예측기나 필터링 목록을 다른 아키텍처에 그대로 재사용할 수 없다 (Section 3.2.1).
- **Duplication 기반 설명이 적용되지 않는 데이터다.** FineWeb에 sequence-level 중복이 없으므로 중복이 많은 실제 corpus에서의 거동은 이 실험이 답하지 않는다 (Section 3.2).
- **Temperature 결과가 선행 연구와 상충한다.** 높은 $T$가 추출형 암기를 줄인다는 본 논문의 결과는, 낮은 $T$가 MIA에 덜 취약하다는 Jagielski et al. (2023)과 방향이 다르다고 저자들이 직접 적는다 (Section 3.1).
- **암기 예시 제거는 완전한 해법이 아니다.** $D_{clean}$으로 재학습하면 이전에 없던 **4개**가 새로 암기된다 (privacy onion effect, Carlini et al. 2022b) (Section 4.2).
- **Hard distillation 비교는 PPL로 할 수 없다.** baseline은 실제 데이터, student는 teacher 합성 출력에 최적화되므로 held-out PPL이 구조적으로 baseline에 유리하다. 그래서 downstream task로 대체했다 (Section 6).
- **Pre-training 설정은 "early experiments"로 명시**되어 있다 (Appendix A.7).
- **Conclusion의 표현 톤 차이**: hard distillation 위험을 Section 6에서는 "greater risk (2.7×)"로, Conclusion에서는 "slightly higher risk"로 쓴다.

## 6. 우리 실험과의 관계

우리 실험은 interpolated teacher spectrum(DeepSeek-R1-Distill-Qwen-1.5B ↔ Qwen2.5-Math-1.5B-Instruct, $\lambda$ = instruct 쪽 가중치)에서 CoT를 뽑아 Qwen2.5-0.5B-Instruct에 **LoRA r=16**으로 증류하고, 2,113개 공유 MATH 문제에 대해 adapter가 흡수한 정보를 **bit 단위**($W$, $\Delta W$, $CL$)로 측정한 것이다. 이 논문과의 관계를 정리하면 다음과 같다.

### 6.1 이미 확립되어 있어서 우리가 다시 주장할 필요가 없는 것

1. **"teacher 생성 시퀀스로 CE 학습하는 증류가 더 위험하다"는 이미 정량화되어 있다.** 우리 파이프라인은 teacher가 생성한 CoT에 대한 CE 학습, 즉 **sequence-level(hard) distillation**이다. 이 논문 Section 6이 정확히 그 변종을 다루며, 총 암기율은 soft와 같지만 **teacher 전용 difficult 예시 상속이 2.7배(50 vs 18개)**임을 보였다. 우리의 "CoT distillation은 암기를 쓴다"는 관찰은 **이 결과와 정합적**이고, 우리 논지의 출발점으로 인용하면 된다 — 새로 증명할 대상이 아니다.
2. **"어떤 텍스트가 외우기 쉬운가"의 예측 변수는 이미 있다.** zlib entropy와 perplexity가 **둘 다 낮을수록** 암기된다(계수 −4.50, AUC 0.9998). 우리 결과에서 **짧은 instruct-style CoT($\lambda \approx 0.8$–$1.0$)일수록 $\Delta W/W$가 1.19까지 오르고, 긴 R1-style CoT($\lambda = 0$)에서 0.09에 그치는** 패턴은 바로 이 축으로 설명될 여지가 크다. 짧고 정형적인 CoT = 낮은 엔트로피 = easy-to-memorize. **우리 각 $\lambda$의 CoT target에 대해 zlib entropy를 계산해 $\Delta W/W$와 상관을 보면, 이 논문의 예측 변수가 bit 척도에서도 성립하는지 바로 검증할 수 있다.** 이건 값싼 추가 실험이고, 성립하면 우리 트렌드에 기존 문헌 기반의 메커니즘 설명이 붙는다.
3. **암기 측정의 표준 정의와 robustness 체크 방식**: 50-token prefix → 50-token exact suffix match(discoverable memorization), 그리고 BLEU>0.75 근사 암기와 100-token 버전. 우리가 이미 본 **학습 CoT의 verbatim prefix 재현 길이 2배**는 이 계열의 지표이므로, 여기 정의에 맞춰 비율(%)로 다시 보고하면 기존 문헌과 바로 비교 가능한 숫자가 된다.
4. **KD가 CE fine-tuning보다 덜 외운다는 대조 실험 설계**: teacher / baseline / student 3원 비교. 우리에게는 **동일 데이터 CE baseline이 없다.** 이 논문이 그 baseline의 필요성과 해석 방식을 이미 정립해 두었다.

### 6.2 이 논문이 **다루지 않은** 것 (= 우리 기여가 설 자리)

1. **bit 단위 측정이 전혀 없다.** 이 논문의 암기는 **예시 단위 이진 판정의 비율(%)**이다. codelength도, 절약된 bit도, "업데이트가 물리적으로 실어 나르는 정보량"도 없다. 우리의 $W$ / $\Delta W$ / $CL$ 프레임은 여기에 겹치지 않는다. 특히 **held-out으로 보정한 $\Delta W$(일반화를 뺀 순수 암기분)** 같은 연속량은 이 논문의 이진 지표로는 표현 불가능하다.
2. **PEFT / LoRA가 없다.** 모든 student·baseline이 **full fine-tuning**이다. adapter 용량, rank, 배치 같은 변수는 전혀 등장하지 않는다. 따라서 우리의 **"$CL \approx 1.585$ bits/param이 모든 $\lambda$에서 동일하다"**는 결과 — 즉 *파일이 전달하는 bit는 고정인데 그 bit가 담는 내용이 일반화에서 암기로 옮겨간다* — 는 이 논문의 축과 직교한다. (이 축은 오히려 `2607.21351_Adapter-Capacity-Bits.md`와 이어진다.)
3. **reasoning / CoT 데이터가 없다.** 데이터는 전부 웹 텍스트 language modeling(FineWeb, WikiText-103, Nemotron-CC-v2)이다. **MATH도, 수학 추론도, 정확도 벤치마크도 없다.** "추론 능력 전이"와 "암기"의 상호작용은 이 논문의 범위 밖이다 (Related Work에서 Distilling Step-by-Step을 언급만 한다).
4. **teacher가 하나로 고정되어 있다.** teacher spectrum도, 모델 병합/보간도, $\lambda$ 같은 연속 knob도 없다. 이 논문이 움직이는 변수는 **temperature $T$, soft vs hard, 아키텍처, 데이터셋**뿐이다. 따라서 **"teacher를 보간해 CoT 스타일·길이를 연속적으로 바꾸면 암기 비중이 단조 증가한다"**는 우리 결과는 선행 연구에 대응물이 없다. **$W$가 $\lambda$에 따라 27배 변하는 것**, **$\lambda \approx 0.5$ 근처에서 held-out $W$의 부호가 바뀌는 것**도 마찬가지다.
5. **CoT 길이/스타일 자체를 변수로 두지 않는다.** target 시퀀스 길이는 256으로 고정이고, 생성 길이가 암기에 미치는 영향은 검토하지 않는다.
6. **utility 붕괴 사례가 없다.** 이 논문에서 증류는 항상 baseline보다 **좋다**(val loss, PPL, LAMBADA, Winogrande 모두). 우리가 관찰한 **long-CoT 증류가 repetition loop로 MATH-500 정확도를 31.8% → 12.8%로 무너뜨린 현상**은 이 논문의 어떤 결과로도 예측되지 않는다. "작은 student에 과도하게 긴 CoT를 밀어 넣었을 때의 실패 모드"는 미개척 영역이다.
7. **메커니즘 설명의 방향이 다르다.** 이 논문은 **loss 형태(KL vs CE)**로 암기 차이를 설명한다(forced memorization). 우리는 loss를 고정한 채 **teacher 출력 분포의 성격**만 바꿔서 암기 비중을 움직였다. 즉 **"같은 hard-CE 증류 안에서도 teacher가 무엇을 생성하느냐에 따라 암기/일반화 비중이 10배 이상 달라진다"**는 것이 우리 쪽 축이다.

### 6.3 포지셔닝 한 줄

> 이 논문은 **"KD는 일반 fine-tuning보다 덜 외운다, 단 hard distillation은 예외적으로 teacher 암기를 2.7배 더 물려받는다"**를 웹 텍스트·full fine-tuning·이진 추출 지표로 확립했다. 우리 작업은 그 **hard distillation 쪽 가지를**, reasoning CoT 도메인에서 **LoRA adapter의 bit 단위 회계**로 열어 보고, **teacher 자체를 연속적으로 움직였을 때** 그 bit 안에서 암기가 일반화를 밀어내는 과정을 보인다.

### 6.4 이 논문을 읽고 우리 실험에 바로 반영할 것

- **동일 데이터 CE baseline 추가**: 현재 우리에겐 "증류 없이 같은 MATH 문제에 LoRA SFT" 대조군이 없다. 이 논문의 3원 비교 구조를 따르면 $\Delta W$의 절대 수준을 해석할 기준이 생긴다.
- **$\lambda$별 CoT target의 zlib entropy 계산**: §6.1-2에서 말한 검증. $\Delta W/W$의 단조 상승이 엔트로피 축으로 설명되는지 확인.
- **discoverable memorization(%) 병기**: 우리 verbatim prefix 결과를 $k=50, L=100$ exact-match 비율로도 보고해 기존 문헌 수치(0.07% vs 0.17% 등)와 같은 눈금에 올린다.
- **temperature를 knob으로 추가 고려**: 이 논문은 $T$를 올리면 암기가 준다고 보고한다. 우리 파이프라인은 hard distillation이라 $T$가 직접 적용되지 않지만, teacher 생성 시 sampling temperature가 유사 효과를 낼지 검토할 가치가 있다.
