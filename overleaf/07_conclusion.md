# 7. Conclusion

- CoT 증류에서 LoRA adapter가 쓰는 정보를 bits로 측정하고, 일반화와 암기로 나누어 분석함
- teacher 스타일을 가중치 보간으로 연속적으로 바꾸고, 여러 student 계열·규모에서 같은 실험을 반복함
- 학습 전 student 기준의 정보 밀도가 adapter에 써지는 것의 성격을 결정했음
   - teacher 스타일과 student 계열은 밀도를 통해서만 작용했음
   - 토큰 수를 맞춰도 관계가 유지되었고, 반복 학습은 같은 데이터를 암기 쪽으로 옮겼음
- bits는 정확도를 직접 예측하지 않았으며, 긴 CoT의 정확도 하락은 생성이 끝나지 못하는 데서 크게 비롯되었음
- 밀도는 학습 전에 계산할 수 있으므로, 증류 데이터와 teacher를 고를 때 무엇이 써질지를 미리 가늠하는 신호로 쓸 수 있음

- (구성 메모) 새 해석 없이 RQ1–3의 답을 한 줄씩 요약함
