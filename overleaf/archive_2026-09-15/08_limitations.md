# Limitations

- LoRA 설정을 하나로 고정했음
   - 모든 linear 층에 rank 16만 사용했으며, rank나 적용 위치에 따라 밀도와 암기 비율의 관계가 달라질 수 있음
   - full fine-tuning에서도 같은 관계가 성립하는지는 확인하지 않았음
- 수학 추론 중심의 평가임
   - 학습 데이터는 MATH train이며, 평가도 수학 벤치마크와 GPQA-Diamond에 한정됨
   - 증류가 이득인 다른 도메인에서 같은 관계가 성립하는지는 확인하지 않았음
- student 규모가 3B 이하임
   - 더 큰 student에서는 밀도 범위와 암기 비율의 관계가 달라질 수 있음
- 생성 길이 한도(8,192토큰)의 영향이 있음
   - 긴 CoT 조건에서 teacher 풀이와 student 생성이 많이 잘렸으며, 공통 문제 집합도 이 한도의 영향을 받음
   - OLMo-2-1B는 문맥 한도 4,096 때문에 학습·평가 길이를 줄였고, 긴 CoT 데이터 일부가 잘렸음
- 보조 실험의 범위가 좁음
   - 토큰 수 통제, 반복 학습 곡선, seed 반복은 쌍 A × Qwen2.5-0.5B에서만 수행했음
   - 반복 학습 곡선은 두 끝점(λ = 0, 1)에서만 그렸음
- 측정 지표의 한계
   - 암기 비율은 held-out 이득을 토큰 수로 환산해 정의했으며, 학습·held-out CoT의 길이 분포 차이에 영향을 받을 수 있음
   - 가중치 부호 길이 CL은 양자화 기준의 문턱에 따라 계단식으로 변해 조건 간 비교에는 적합하지 않았음
- teacher 쌍 구성의 한계
   - 네 쌍 중 세 쌍의 추론 쪽이 DeepSeek-R1 증류 모델이며, R1이 아닌 추론 모델은 한 쌍(Qwen3-4B)뿐임
   - 따라서 추론 모델의 학습 방식 자체가 결과에 주는 영향은 분리해 주장하지 않음
- 대부분의 조건을 seed 하나로 학습했음
