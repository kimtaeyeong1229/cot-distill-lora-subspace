# Appendix
## A. Experimental Details
- **(데이터)**
    - MATH train split에서 MATH-500과 겹치는 문제를 뺀 뒤 4,000문제를 뽑고, 여섯 $\lambda$의 teacher가 각각 이를 풂
    - 각 $\lambda$에서 끝까지 쓰고, 답이 맞고, 8,192토큰 안에 통째로 들어가는 풀이만 남김
    - 여섯 $\lambda$가 모두 통과한 문제만 취해 300문제를 학습 분포 안의 검증용으로 떼어 두고, 나머지(쌍 A, B, C 각각 2,113, 2,261, 1,015문제)로 학습함
    - OLMo-2는 문맥이 4,096토큰이라 가장 긴 $\lambda=0$ 풀이 일부는 뒷부분이 잘린 채 학습됨
- **(학습)**
    - 모든 student는 선형 층 7종에 $r=16$, $\alpha=32$의 LoRA adapter를 붙이고, batch 크기 32와 학습률 $2\times10^{-4}$로 3 epoch 학습함. 최대 길이는 8,192토큰(OLMo 4,096)임
    - 학습은 PyTorch ([Paszke et al., 2019](https://proceedings.neurips.cc/paper_files/paper/2019/hash/bdbca288fee7f92f2bfa9f7012727740-Abstract.html)), Transformers ([Wolf et al., 2020](https://aclanthology.org/2020.emnlp-demos.6/)), [PEFT](https://github.com/huggingface/peft)로 하고, 생성은 LoRA adapter를 병합하지 않고 그대로 서빙하는 vLLM ([Kwon et al., 2023](https://doi.org/10.1145/3600006.3613165))으로 함
- **(생성과 평가)**
    - teacher와 student 모두 $T=0.6$, top-p 0.95로 생성하며, 최대 길이는 teacher 8,192토큰, student 7,680토큰(OLMo 3,840)임
    - 모든 adapter가 푸는 MATH-500의 앞 200문제는 난이도와 과목 비율이 MATH-500 전체와 같음
    - GSM8K는 앞 200문제, GPQA-Diamond는 전체 198문제를 같은 설정으로 씀
    - 학습 전 student는 adapter가 없으므로 adapter seed 대신 생성 seed를 셋 바꿔 평균 ± 표준편차를 냄
- **(생각 측정)**
    - student는 첫 응답의 반성 표현을 셈. 같은 문장을 되풀이하는 조건은 반복이 쌓이기 전인 각 응답의 앞 300단어에서 셈
    - teacher의 think rate와 반성 표현도 같은 방식으로, teacher가 4,000문제에 쓴 풀이 전체에서 셈
- **(생각 feature)**
    - base Llama-3.2-1B 모델로 학습된 공개 SAE를 씀 ([EleutherAI SAE](https://huggingface.co/EleutherAI/sae-Llama-3.2-1B-131k))
    - 학습 전 Llama student가 $\lambda=0$과 $\lambda=1$ teacher의 풀이를 읽을 때 $\lambda=0$ 쪽에서 훨씬 강하게 켜지는 feature를 고름
    - 반성 표현을 끼우거나 지우는 것만으로 켜지고 꺼지는 feature는 버리고 ([Ma et al., 2026a](https://arxiv.org/abs/2601.05679)), 두 반증 검사를 모두 통과한 feature만 남김
    - base 모델로 학습된 SAE를 학습 전 student와 adapter를 붙인 student에 쓰므로 재구성 오차도 확인함
    - 각 adapter가 자기 첫 응답을 읽을 때 고른 feature의 평균 활성을 재며, $\lambda=0$ teacher 풀이에서의 활성을 1로 맞춤
- **(순열 검정)**
    - 다섯 $\lambda$ 구간에 걸쳐 $R$의 낙차와 teacher think rate의 낙차의 상관을 구하고, teacher 풀이 속 반성 표현의 낙차로도 같은 검정을 함
    - 같은 쌍의 student 셋은 teacher를 공유하므로 쌍마다 세 student의 평균 상관을 통계량으로 쓰고, 세 쌍의 teacher 순서를 각각 섞는 모든 경우(120³가지)로 정확한 $p$를 냄
- **(seed 2개로 찾은 구역)**
    - adapter가 둘이면 식 4에서 짝지은 방향의 고윳값이 $(1+\cos\theta)/2$라 0.5 기준은 거의 모든 방향을 남기므로, 60° 안으로 겹치는 방향($\mu > 0.75$)만 남김
    - 두 구역의 겹침은 seed 2개로 찾은 구역 $V_{\text{seed}}$가 공유 구역의 차원을 덮는 비율 $\lVert V_{\text{seed}}^\top V \rVert_F^2 / k$로 잼
- **(편집)**
    - 제거는 $B \leftarrow B - V(V^\top B)$로 구현하므로 $A$와 rank는 그대로임
    - 이식에서는 $\beta=4$와 8에서 모든 조건이 같은 문장을 되풀이하므로, 이 값들은 비교에서 뺌
    - 같은 길이로 끊기는 칸마다 원래 adapter를 공유 구역을 뺀 adapter의 평균 길이(아홉 칸 평균 1,076토큰)에서 멈추고 답을 쓰게 함
    - 제거의 대조는 같은 에너지를 $V$와 직교하는 쪽의 에너지가 가장 큰 방향에서 빼거나, 업데이트 전체를 같은 양만큼 줄이거나, 가장 큰 특잇값 성분부터 같은 에너지만큼 빼는 것임. 이식의 대조는 $V$ 밖의 성분이나, 같은 에너지로 줄인 $\lambda=0$ 업데이트 전체를 더하는 것임
    - seed 2개로 찾은 구역의 비교 방법은 Gold-Switch 기준($\tau=0.6$)으로 가장 큰 성분 빼기, 답 앞에 생각을 끝냈다는 문장을 넣는 think-skip 프롬프트, 같은 길이로 끊기, $\lambda=1$ adapter와 반반 병합하기, 학습 전 student임
    - student는 `</think>` 태그를 배우지 않았으므로, think-skip 프롬프트는 태그 없이 문장만 넣음
## B. Measuring the Switch
- $R$은 teacher가 다른 adapter끼리의 겹침(분자)을 데이터만 다른 adapter끼리의 겹침(분모)으로 나눈 값임
- 분자는 아홉 칸 모두 $\lambda=0.2$의 0.31–0.64에서 $\lambda=1$의 0.03–0.09로 떨어짐
- 분모는 칸마다 다른 수준에 머묾. 다른 칸은 $\lambda=1$에서도 0.14–0.48을 유지하지만, A/Qwen은 $\lambda=0.2$의 0.39에서 $\lambda=0.4$의 0.07, $\lambda=1$의 0.04로 무너져, 분자가 다른 칸만큼 떨어져도 $R$이 $\lambda=0.4$부터 0.62–0.74에 머묾
- seed만 다른 adapter끼리의 겹침은 기준선으로 쓰지 않음. 같은 seed로 학습한 adapter끼리는 LoRA 초기화를 공유해 $\lambda=0.2$의 겹침이 0.31–0.68로 부풀기 때문임(seed가 다르면 0.11–0.21)
- 초기화 몫을 빼도 큰 낙차는 남음. 다른 seed 사이의 겹침은 쌍 A에서 0.11–0.13에서 0.04로($\lambda = 0.2 \to 0.4$), 쌍 B에서 0.15–0.17에서 0.07–0.09로($0.4 \to 0.6$), 쌍 C에서 0.16–0.18에서 0.03–0.05로($0.4 \to 0.8$) 떨어짐
- 같은 구간에서 $R$의 분자는 3–12배 떨어지지만 업데이트 노름은 1.1–1.4배만 줄어, 낙차는 업데이트가 작아진 결과가 아님
- 표 2는 모든 $\lambda$에서 teacher think rate와 teacher 풀이 속 반성 표현을 student의 반성 표현과 나란히 놓은 것으로, 4.1의 근거임
- 표 3은 그림 2가 그리는 칸별 $R$을, 표 4는 쌍마다 두 낙차의 상관과 순열 검정의 $p$를 보임
- 표 5는 칸마다 전환 $\lambda$, 전환 전과 후에 만든 공유 구역의 크기, 그리고 그림 2(아래)가 $\lambda$에 따라 그리는 덮는 비율을 보임
